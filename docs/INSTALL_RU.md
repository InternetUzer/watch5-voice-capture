# Установка Watch5 Voice Capture — прототип

**Статус:** исходники не скомпилированы в HAP и не проверены на физических Huawei Watch 5.

## Подготовка

1. На часах найдите версию HarmonyOS в Настройки → Об устройстве.
2. Включите режим разработчика и отладку по Wi-Fi, если опция доступна.
3. Установите DevEco Studio с SDK, совместимым с версией часов.

## Сборка

1. Откройте каталог `watch/` в DevEco Studio.
2. Дождитесь синхронизации зависимостей и проверьте совместимость API и конфигурации hvigor.
3. При несовместимости создайте проект Wearable / Empty Ability / Stage под конкретный SDK, перенесите `entry/src/main/ets`, ресурсы и разрешения из `module.json5`.
4. Настройте подпись разработчика (Signing Configs), затем выполните Build → Build Hap(s).

## Установка

```bash
hdc tconn IP_ЧАСОВ:ПОРТ
hdc list targets
hdc install /path/to/entry-default-signed.hap
```

Запустите Voice Capture, предоставьте разрешение на микрофон и нажмите СТАРТ. Проверьте срабатывание и запись при погашенном экране. Приложение не включает микрофон скрыто и не возобновляет запись после перезагрузки.

## Сервер

Python 3.11+:

```bash
cd server
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export WATCH_API_KEY='длинный_секретный_ключ'
export WATCH_STORAGE_DIR='/путь/к/архиву'
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Перед публикацией сервера установите HTTPS-прокси и валидный сертификат. На часах укажите полный URL вида `https://host/v1/recordings` и API-ключ; после завершения сессии нажмите «Отправить файлы».

## Известные ограничения

- Это предварительный код; компиляция ArkTS и фоновая запись на Watch 5 не подтверждены.
- Детектор реагирует на энергию звука, не различает речь и шум.
- Ограничение файла для отправки — 8 MiB; трёхминутные WAV могут превышать лимит.
- Выгрузка ручная, без докачки, идемпотентности и автоматического удаления.
- Сессия запускается пользователем и сопровождается индикатором микрофона.
