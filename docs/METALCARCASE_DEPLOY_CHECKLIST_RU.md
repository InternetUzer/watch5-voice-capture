# Проверка серверной части до подписи Huawei Watch 5

**Подтверждено:** исходный проект компилировался как неподписанный HAP в DevEco Studio 6.1.1 (по предоставленному журналу), серверные тесты GitHub Actions выполняются.

**Не подтверждено:** доступ к REG.RU/ISPmanager, DNS и TLS для `voice.metalcarcase.ru`, реальная выгрузка в пользовательский Яндекс Диск, установка и работа на часах.

## Подготовить сервер

1. В ISPmanager создать отдельный Python-сайт на поддомене `voice.metalcarcase.ru`, выпустить для него сертификат TLS.
2. Получить Яндекс OAuth-токен с правом записи в Диск. Не отправлять токен в ChatGPT или GitHub.
3. Под SSH под пользователем хостинга: скачать `server/scripts/bootstrap_reg_ru.sh` из своего репозитория и выполнить **после проверки содержимого** или использовать команды из `METALCARCASE_DEPLOY_RU.md`. Скрипт НЕ изменяет существующий сайт metalcarcase.ru.
4. Разместить `passenger_wsgi.py` в каталоге нового Python-сайта (если он использует WSGI/Passenger) и задать Python из `~/watch5-voice-capture/server/.venv`.
5. Перезапустить только новый сайт и открыть `https://voice.metalcarcase.ru/health`.

## Проверить реальную загрузку без часов

На сервере или локальном компьютере c доступом к серверу указать ключ устройства через переменную `WATCH_API_KEY` и выполнить:

```bash
python3 server/scripts/smoke_upload.py https://voice.metalcarcase.ru/v1/recordings
```

Скрипт загружает 1 секунду **тишины**, а не разговор. Ответ `201` с `"cloud_synced": true` и `disk:/Watch5-Voice-Capture/...` подтверждает цепочку HTTPS → сервер → Яндекс Диск. После этого проверить, что файл реально появился на своём Диске. Если приходит 502 — проверить OAuth и доступ к Яндекс Диску; локальный WAV сохраняется для повторной отправки.

## Дальше

Подписать HAP через Huawei Developer, установить на часы, дать разрешение на микрофон, запустить сеанс мониторинга и проверить создание файлов. Текущая версия отправляет их вручную.

Расшифровка в этом чате требует вложения файла либо доступной ссылки. Прямое чтение личного Яндекс Диска из этого чата не настроено.
