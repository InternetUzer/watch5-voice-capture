# Яндекс Диск: доступ для проверяемой загрузки v2

OAuth-токен хранится только в защищённом серверном окружении. На часах и телефоне —
отдельный ключ устройства для HTTPS API. Не присылайте токены в чат и не добавляйте в Git.

## Необходимые права

Для текущей папки `disk:/Watch5-Voice-Capture` нужны **запись** (`cloud_api:disk.write`)
и **чтение** (`cloud_api:disk.read`). Чтение нужно серверу, чтобы проверить размер и SHA-256
именно загруженного WAV и его timeline JSON перед разрешением удалить оригинал.
Разрешение чтения распространяется на весь Диск; код обращается только к папке архива.

В [Яндекс OAuth](https://oauth.yandex.ru/) откройте существующее приложение, добавьте
право чтения, сохраните настройки и получите новый токен с обновлёнными правами.
Старый токен автоматически считать обновлённым нельзя. Введите новый токен только в
защищённое поле серверной настройки; не вставляйте его в команды или скриншоты.

Если нужен доступ строго к папке приложения вместо всего Диска, это отдельный вариант:
разрешение `cloud_api:disk.app_folder` и переход на пространство `app:/`. Эта ветка
использует существующее `disk:/`; она не выполняет такой перенос автоматически.

## Проверка

Перед отправкой аудио сервер проверяет право читать метаданные папки. После PUT он
запрашивает `type,size,sha256` и сравнивает размер/хеш. Затем отдельно загружает и проверяет
`.timeline.json`. До завершения обеих проверок `cloud_verified: true` не возвращается.
Отсутствие прав, задержка облака и сетевые ошибки сохраняют локальные файлы для повтора.

На сервере, после обновления защищённого окружения и перезапуска только voice-сервиса:

```sh
cd ~/watch5-voice-capture/server
.venv/bin/python scripts/smoke_upload.py https://voice.metalcarcase.ru/v1/recordings --seconds 600
```

Скрипт сам читает ключ устройства из закрытого серверного env-файла, генерирует
синтетическую тишину и проверяет HTTP 201, флаги, имя, размер и SHA-256 ответа.
Результат v2: WAV около 19,2 МБ и JSON в приватной папке, UTC-время начала в имени.
