# DevEco Studio 6.1.1.280 — настройки сборки

Для IDE 6.1.1 Huawei указывает значение `"modelVersion": "6.1.1"`. Оно должно совпадать в:

- `watch/hvigor/hvigor-config.json5`
- `watch/oh-package.json5`

`@ohos/hvigor-ohos-plugin` не закреплять вручную в `dependencies`.

При ошибке `00303024`:

1. Использовать актуальную копию проекта.
2. Проверить указанные `modelVersion`.
3. Закрыть IDE и удалить **только кэш конкретного проекта**, если ошибка сохраняется.
4. Открыть каталог `watch` и выполнить Sync Project / Build HAP.

Если проект по-прежнему требует миграции, использовать встроенный Migration Assistant; при отсутствии ассистента создать новый Wearable Empty Ability в DevEco 6.1.1 и перенести `ets`, ресурсы и разрешения из нашего исходника. Это сохраняет свежую структуру IDE.

**Важно:** проект пока не компилировался и не тестировался на физических Watch 5. SDK 12 в `build-profile.json5` может не соответствовать установленной SDK/прошивке и потребует отдельного согласования. Не следует произвольно повышать target SDK без проверки совместимости.
