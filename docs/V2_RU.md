# Watch5 + Прораб+: настройка и приёмка v2

Целевые устройства: Huawei Watch 5, прошивка 6.1.0.330 SP51; Samsung S24 FE.
Наушники: любые Bluetooth-наушники, чей микрофон Android предоставляет как SCO/BLE input.
Одного факта Bluetooth-подключения недостаточно, если ОС не предоставляет аудиовход.

## Что делает код

СТАРТ → ожидание речи → запись с 2 с предзаписи → ещё 5 с после речи → пауза в том же
файле → продолжение при речи. По 10 минут **сохранённого аудио**, не времени на часах.
СТОП сохраняет остаток, поэтому последний файл может быть короче 10 минут. Смена источника,
ошибка или перезапуск тоже могут создать короткий файл; дополнять его искусственной тишиной
код не будет. При выборе «непрерывно» пауз нет. «Слушать» включает динамик часов и само по
себе ничего не сохраняет; запись можно включить отдельно.

Наушники подключены к телефону: телефон сохраняет оригинал, часы управляют и получают
прямой звук. Потеря канала часов не обрывает телефонный архив. Без доступного микрофона
наушников используется микрофон часов, если система разрешила его запуск. UI показывает
фактическое состояние, неподтверждённый СТОП отдельно. Вне связи нажми СТОП также в
уведомлении помощника на телефоне, если нужна немедленная остановка.

Файлы часов остаются на часах, файлы наушников — на телефоне. Отправка автоматически идёт
через доступную устройству сеть. При работающем помощнике возможна передача файла часов
на телефон через Wear Engine; оригинал удаляется только после проверки Диска. Для Wi-Fi,
мобильной сети и системного Bluetooth-интернета используется стандартный сетевой маршрут.
Live-слушание приоритетнее массовой передачи файлов.

## Что ещё нужно для запуска на устройствах

1. Собрать **эту ветку** в DevEco с API 23; старый отчёт о сборке v1 не подтверждает v2.
2. Оформить подпись/профиль Huawei для часов и разрешённый доступ к Wear Engine для обоих
   приложений. Без регистрации сервиса и подписей гарантировать связь нельзя.
3. Собрать парную ветку TECHNADZOR `codex/watch5-companion-v2`; App ID через
   `WEAR_ENGINE_APP_ID` (публичная настройка). Учитывать пакет `.debug` тестовой сборки.
4. В защищённых полях ввести ключ устройства. OAuth Яндекса хранится только на сервере.
   В настройках связи указать публичные отпечатки сертификатов приложений.
5. Разрешить Huawei Health связь с часами. В Прораб+ → настройки → часы открыть помощник
   и включить его перед сеансом. Без наушников он может принимать файлы часов.
6. Обновить OAuth на сервере: для проверки файлов нужен доступ на чтение, см. YANDEX_DISK_RU.md.
7. Обновить только отдельный сервер voice.metalcarcase.ru до v2. Проверить HTTPS/API,
   полный 10-минутный WAV и `.timeline.json` на Диске. Основной сайт не переносить.

## Ограничения, которые нельзя выдавать за готовые функции

- Подписанный HAP и реальные аудиомаршруты ещё не проверены. Автотесты ядра не заменяют
  сборку ArkTS, задержку прямого звука и фоновую работу на конкретной прошивке.
- Автоматическое включение микрофона после перезагрузки не реализовано: ОС ограничивает
  такие старты. Очередь сохраняется; запись возобновляется явным СТАРТ.
- Пока приложение активно, сеть вызывает немедленную попытку отправки. После завершения
  процесса HarmonyOS WorkScheduler выбирает время сам (повтор не чаще 2 ч и возможна
  дополнительная задержка); обещать «мгновенно при появлении сети» нельзя. Android использует
  WorkManager. Открытие приложения также возобновляет очередь.
- Детектор — эвристика голосовой полосы, не обученная модель VAD. Проверить на стройке:
  речь, ветер, музыка, инструмент. Чувствительность регулируется.
- Запись работает с системной индикацией микрофона. Все несинхронизированные файлы
  сохраняются; при остатке около 8 МБ запись останавливается без удаления очереди.
- При аварии PCM восстанавливается по заголовку и журналу; точные отметки последней
  неполной секунды могут отсутствовать, что отмечается `recovered: true`.

## Приёмочные сценарии

- Две реплики с минутой тишины: один файл, 5 с хвоста, верные реальные времена в timeline.
- 21 мин непрерывно: два WAV по 10:00 и остаток 1:00 после СТОП; совпадают все samples.
- Режим «слушать»: нет файлов; включение записи не останавливает прослушивание.
- Погасить экран, свернуть приложения; проверить 20+ минут и состояние батареи.
- Отключить интернет, затем восстановить: очередь сохраняется, загрузка подтверждается
  размером/хешем; локальные файлы исчезают только после проверки WAV и JSON на Диске.
- Отключить телефон от часов при записи наушников: запись остаётся на телефоне, UI часов
  показывает отсутствие подтверждения. СТОП вне связи не выдаётся за успешно выполненный.
- Убить процесс/перезапустить устройство: восстановить `.part`, вернуть очередь, никаких
  незаметных стартов микрофона. Проверить низкую память и прерывание телефонным звонком.
- Открыть WAV обычным плеером, сверить начало по UTC в имени, затем паузы по timeline JSON.
