# Обновление часов 0.2.1

Исправлена остановка загрузки до HTTP-запроса, если система отказала в фоновой задаче.
В этом случае передача продолжается в открытом приложении; экран просит оставить его открытым.
Это возможная причина наблюдавшегося сбоя, а не подтверждённый диагноз конкретных часов.
Добавлены время последней попытки, повтор загрузки, HTTP-код / этап / числовой код ошибки
без вывода ключей, URL из исключений или тела ответа сервера.
«Восстановить подключение» явно повторяет импорт личного профиля, если он есть,
и восстанавливает адрес https://voice.metalcarcase.ru/v1/recordings.
Без личного профиля сохраняется существующий ключ Asset Store; новый ключ не создаётся.
Обычный запуск/обновление по-прежнему не перезаписывает ручную настройку тем же профилем.

## Установка на компьютере владельца

Сертификат подписи находится на компьютере владельца. Готовый подписанный HAP здесь
не выпускался: требуется сборка в DevEco и проверка на Watch5.
31 Node-тест логики пройден; это не заменяет ArkTS-сборку и тест устройства.

В PowerShell:

```powershell
Set-Location 'C:\Users\Serega\DevecostudioProjects\watch5-voice-capture-v2\watch'
git pull --ff-only origin codex/voice-capture-v2
Test-Path '.\entry\src\main\resources\rawfile\personal-setup.json'
```

Если Git сообщил конфликт локальных изменений — остановиться, не делать reset/clean.
Локальные файлы подписи и конфигурации сборки сохраняются; секретный rawfile игнорируется Git.
Если Test-Path выдаёт False, до удаления приложения создать профиль:

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\Set-PersonalSetup.ps1
```

В скрытый ввод вводится WATCH_API_KEY сервера, не OAuth Яндекса. Профиль и содержащий
его личный HAP нельзя публиковать или пересылать: ключ извлекается из HAP.

Открыть этот каталог watch в DevEco, синхронизировать и собрать подписанный HAP
с прежней конфигурацией подписи. Сначала убедиться, что сборка успешна.

## Очистка старых записей — только по запросу владельца

Владелец запросил удалить старые записи на часах. Для полной очистки после успешной
сборки остановить запись, удалить Voice Capture через интерфейс часов и затем
установить новую сборку кнопкой Run в DevEco. Удаление приложения очищает его локальные
данные и ключ, поэтому наличие личного профиля нужно проверить ДО удаления.
Это не удаляет файлы на Яндекс Диске, серверные копии или записи телефона.
Без запроса на очистку устанавливать поверх старой версии, не удаляя приложение.

## Проверка

На главном экране должна быть версия 0.2.1. Подключить часы к Wi-Fi с интернетом.
Проверить в настройках «Ключ устройства сохранён» и адрес API. При необходимости,
когда запись и загрузка остановлены, нажать «Восстановить подключение».
Создать короткую запись, нажать СТОП, затем «Повторить загрузку» и держать приложение
открытым. Успех: «Все записи на Диске», очередь ноль, новый WAV в Watch5-Voice-Capture.
При сбое передать точный HTTP/числовой код и этап, не ключ и не личный JSON.
Удаление после обычной загрузки по-прежнему возможно только при совпадении
filename, bytes, SHA-256 и обоих флагов cloud_synced/cloud_verified.
